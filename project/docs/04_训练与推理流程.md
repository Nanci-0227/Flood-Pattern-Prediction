# 04 训练与推理流程

项目包含三个训练脚本（对应三大任务）和一个端到端推理脚本。训练脚本均通过 `argparse` 接收命令行参数，并优先从 `config.py` 读取默认超参数。

---

## 1. 训练分割模型 `train_seg.py`

### 数据加载 `FloodDataset`

继承 `torch.utils.data.Dataset`，读取「图片 + 二值掩码」成对数据：

- `image_dir` 下匹配 `.jpg/.jpeg/.png/.bmp` 图片；
- `mask_dir` 下的掩码需与图片同名（`_find_mask` 按 stem 匹配扩展名），掩码非零像素视为积水；
- 支持 `albumentations` 数据增强（水平翻转、亮度对比度）。

### 损失函数 `FocalDiceLoss`

自定义组合损失，继承 `nn.Module`，用于缓解类别不平衡：

- **Focal 部分**：针对积水通道概率计算 focal loss，`alpha=0.25, gamma=2.0`；
- **Dice 部分**：计算积水通道的 Dice 系数损失；
- 最终损失 = `focal + dice_loss`。

### 训练主流程 `main()`

1. 解析命令行参数（图像/掩码目录、epochs、batch_size、lr、val_split 等）；
2. 在图像/掩码对上先划分训练集与验证集，再分别创建训练增强与验证无增强的数据集，避免验证阶段使用随机增强；
3. 构建 `Segmentor` + `FocalDiceLoss` + `AdamW` 优化器 + `CosineAnnealingLR` 学习率调度；
4. 启用混合精度 `GradScaler + autocast`（仅 CUDA 时）；
5. 逐 epoch 训练，验证阶段计算 Dice、IoU、Precision、Recall；
6. 每轮对比最优 Dice，更优则保存 `state_dict` 到 `seg_best.pth`。

### 验证函数 `evaluate(model, loader, device)`

计算验证集 Dice、IoU、Precision、Recall：对 logits 执行 softmax 后，以积水通道 `> 0.5` 得到二值预测并逐样本汇总。

## 2. 训练 LSTM 预测模型 `train_lstm.py`

### 数据准备

- 读取 CSV，要求包含 `ratio` 列；
- 调用 `utils/video_processing.build_lstm_dataset` 切窗生成 `X`（`M, seq_len, 2`）与 `y`（`M, future_steps`）；
- 转为 `TensorDataset` 后按时间顺序划分：较早窗口用于训练，末尾窗口用于验证，避免未来信息泄漏。

### 训练流程

1. 构建 `LSTMPredictor`（`input_dim=2, hidden=64, layers=2`）；
2. 损失函数 `MSELoss`，优化器 `Adam`；
3. 逐 epoch 训练，计算训练/验证 MSE，并报告验证 MAE、RMSE；
4. 保存验证损失最低的模型到 `lstm_best.pth`。

---

## 3. 训练融合模型 `train_fusion.py`

### 特征加载 `load_features(csv_path)`

- 特征列常量：`["ratio", "change_rate", "pred_ratio", "rain", "drain_rate"]`；
- 仅保留 CSV 中存在且在常量列表中的列；`ratio`、`rain` 为必需列；
- **标签处理**：
  - 若 CSV 有 `label` 列，直接使用；
  - 否则调用 `config.rule_risk_index` 按规则生成伪标签（用于快速跑通，缺省 `pred_ratio` 时用 `ratio` 代替）。

### 训练流程

1. 输入维度 `input_dim = X.shape[1]`（取决于实际特征列数）；
2. 构建 `RiskFusionNet`，损失 `CrossEntropyLoss`（4 分类），优化器 `Adam`；
3. 按 CSV 行序保留末尾时间段为验证集，并输出 Accuracy、Macro-F1 和每类 Recall；
4. 保存验证准确率最高的模型到 `fusion_best.pth`。

## 4. 端到端推理 `infer_video.py`（核心链路）

这是项目的主入口脚本，串起三大任务与兜底逻辑。

### 模型加载函数

| 函数 | 作用 | 权重缺失时 |
| :--- | :--- | :--- |
| `load_segmentor(device)` | 加载分割模型 | 返回 `None` |
| `load_lstm(device)` | 加载 LSTM | 返回 `None` |
| `load_fusion(device)` | 加载融合模型 | 返回 `None` |

### 关键处理函数

- `to_tensor(frame)`：BGR 帧 → 归一化张量 `(1,3,512,512)`，使用 ImageNet 均值/方差。
- `segment_frame(frame, seg_model, device, backend)`：
  - `backend == "unet"` 且模型非空时，用模型预测掩码并 resize 回原分辨率；
  - 否则回退 `hsv_water_mask`。
- `linear_extrapolate(history, future_steps)`：无 LSTM 时的线性外推兜底，用最近 5 个点的斜率外推。
- `lstm_predict(lstm, device, history)`：构造 `[面积比, 变化率]` 特征序列送入 LSTM，取预测序列最后一值。
- `fusion_predict(fusion, device, ratio, change, pred_ratio, rain)`：拼 5 维特征（`drain_rate` 补 0）送入 MLP，返回 `argmax` 风险索引。

### 主流程 `main()`

1. 解析参数：`--video`（必需）、`--backend`（unet/hsv）、`--rain`、`--output`，以及 `--event_log`、`--risk_window`、`--downgrade_hold`；
2. 解析设备 `get_device()`（auto 时优先 CUDA）；
3. 加载三个模型，打印各自的加载/兜底状态；
4. 读取视频信息，计算采样步长 `sample_step = fps * SAMPLE_INTERVAL`（默认 2 秒）；
5. 逐帧遍历：
   - 分割得到掩码，计算 `ratio = mask.mean()`；
   - 满足采样步长时压入 `history`；
   - 计算变化率 `change`；
   - 历史足够时调用 LSTM/外推得到 `pred_ratio`，否则等于当前值；
   - 调用融合/规则得到原始 `risk_idx`，再经风险状态稳定器确定展示等级；
   - 叠加掩码、绘制风险面板，写入输出视频；
6. 视频写完后，若有历史则导出趋势曲线 PNG，并写入风险升级/降级事件 CSV。

### 命令行示例

```bash
python infer_video.py --video data/video/demo.mp4 --backend unet --rain 30
python infer_video.py --video data/video/demo.mp4 --backend hsv --rain 30
```

### 与 config 的耦合点

推理脚本依赖 `config.py` 中的：`SEG_CHECKPOINT / LSTM_CHECKPOINT / FUSION_CHECKPOINT`、`SEQ_LEN / FUTURE_STEPS / SAMPLE_INTERVAL / OVERLAY_ALPHA / RESULT_DIR`、`RISK_LEVELS`、`rule_risk_index`。

## 5. 训练与推理的数据衔接

三个任务并非完全独立，其数据存在上下游关系，这也是整个系统的核心设计：

1. **任务 A（分割）** 输出积水面积比序列；
2. 该序列 → `series_from_ratios` 或 `build_lstm_dataset` → **任务 B（LSTM）** 的训练数据 `ratio.csv`；
3. 面积比、变化率、LSTM 预测值、降雨强度 → 组合成特征 → **任务 C（融合）** 的训练数据 `fusion_features.csv`。

因此，完整训练需要依次完成：分割训练 → 用分割结果生成时序数据 → 训练 LSTM → 生成融合特征 → 训练融合网络。但在缺失任一部分权重时，推理端均可用兜底方案替代，保证演示可独立运行。
