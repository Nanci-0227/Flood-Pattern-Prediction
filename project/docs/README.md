## 项目速览

- **核心链路**：视频帧 → 积水分割 → 面积比/变化率 → LSTM 趋势预测 → 多模态融合 → 四级风险预警 → 可视化输出。
- **三大任务**：
  - 任务 A：积水区域语义分割（U-Net + ResNet50 编码器）；
  - 任务 B：积水面积比时序预测（双层 LSTM）；
  - 任务 C：多模态风险分类（轻量 MLP，蓝/黄/橙/红四级）。
- **鲁棒性设计**：每一级模型权重缺失时均有传统方法/规则兜底，保证全流程可跑通。
- **技术栈**：PyTorch、segmentation-models-pytorch、OpenCV、albumentations、pandas、matplotlib。

## 模块依赖关系

```
config.py  ←──────────────────────────┐
   ▲                                  │
   │                                  │
train_seg.py ──► models/segmentor.py  │
train_lstm.py ─► models/predictor.py  │
train_fusion.py ─► models/fusion.py   │
infer_video.py ─► models/* + utils/*  │
                    ▲                 │
utils/video_processing.py 等 ─────────┘
```

所有模块统一通过 `import config` 共享同一套路径、超参数与规则配置，避免散落魔法数字。
