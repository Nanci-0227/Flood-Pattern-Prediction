# 02 模型实现详解

本项目的三个深度学习模型分别位于 `models/` 目录下，对应三大任务。三个模型均为纯 `torch.nn.Module`，不含训练逻辑（训练逻辑在根目录的 `train_*.py` 中）。

---

## 1. 任务 A：积水区域分割 `models/segmentor.py`

### 类 `Segmentor`

封装 `segmentation_models_pytorch`（简称 `smp`）的 U-Net，用于输出背景/积水二类语义分割概率图。

- **依赖**：`import segmentation_models_pytorch as smp`，缺失时抛出带安装提示的 `ImportError`。
- **构造参数**：
  - `encoder_name`：默认 `"resnet50"`；
  - `encoder_weights`：默认 `"imagenet"`；
  - `in_channels=3`；
  - `classes=2`（背景 / 积水）。
- **内部模型**：`smp.Unet(..., activation=None)`，forward 输出 `(B, 2, H, W)` 的 logits；只在预测阶段执行一次 softmax，避免训练时重复归一化。

关键代码结构：

```python
class Segmentor(nn.Module):
    def __init__(self, encoder_name="resnet50", encoder_weights="imagenet",
                 in_channels=3, classes=2):
        super().__init__()
        self.model = smp.Unet(encoder_name=encoder_name, encoder_weights=encoder_weights,
                              in_channels=in_channels, classes=classes, activation=None)

    def forward(self, x):
        return self.model(x)          # (B, 2, H, W)

    @torch.no_grad()
    def predict_mask(self, x):
        self.eval()
        probs = torch.softmax(self.forward(x), dim=1)
        return probs.argmax(dim=1)    # (B, H, W)，1 表示积水
```

### 函数 `extract_water_ratio(mask)`

由二值掩码 `(B, H, W)` 计算积水面积占比，返回 `(B,)`：

```python
return mask.float().mean(dim=(1, 2))
```

## 2. 任务 B：趋势预测 `models/predictor.py`

### 类 `LSTMPredictor`

双层 LSTM，输入历史面积比与变化率的二维特征序列，回归预测未来若干步的面积比。

- **构造参数**：
  - `input_dim=2`（`[面积比, 变化率]`）；
  - `hidden_size=64`；
  - `num_layers=2`；
  - `dropout=0.2`（仅当 `num_layers > 1` 时生效）；
  - `future_steps=10`（预测未来步数）。
- **前向**：输入 `(B, seq_len, input_dim)` → LSTM → 取最后一个时间步隐状态 → 全连接层输出 `(B, future_steps)`。

```python
class LSTMPredictor(nn.Module):
    def __init__(self, input_dim=2, hidden_size=64, num_layers=2,
                 dropout=0.2, future_steps=1):
        super().__init__()
        self.lstm = nn.LSTM(input_size=input_dim, hidden_size=hidden_size,
                            num_layers=num_layers, batch_first=True,
                            dropout=dropout if num_layers > 1 else 0.0)
        self.fc = nn.Linear(hidden_size, future_steps)

    def forward(self, x):               # (B, seq_len, 2)
        out, _ = self.lstm(x)
        last = out[:, -1, :]            # 取最后一个时间步
        return self.fc(last)            # (B, future_steps)
```

> 注意：这是一个从序列到多步回归的模型，任务 C 中仅使用其预测序列最后一个值 `pred[-1]` 作为最终预测面积比。

## 3. 任务 C：多模态风险融合 `models/fusion.py`

### 类 `RiskFusionNet`

轻量多层感知机（MLP），融合视觉、时序、气象三类特征，输出四级风险分类 logits。

- **构造参数**：
  - `input_dim=5`；
  - `hidden=(16, 8)`；
  - `num_classes=4`（蓝/黄/橙/红）；
  - `dropout=0.1`。
- **结构**：由 `hidden` 参数动态构建若干 `Linear → ReLU → Dropout` 层，最后接一层 `Linear(prev, num_classes)`。

```python
class RiskFusionNet(nn.Module):
    def __init__(self, input_dim=5, hidden=(16, 8), num_classes=4, dropout=0.1):
        super().__init__()
        layers = []
        prev = input_dim
        for h in hidden:
            layers.append(nn.Linear(prev, h))
            layers.append(nn.ReLU())
            layers.append(nn.Dropout(dropout))
            prev = h
        layers.append(nn.Linear(prev, num_classes))
        self.net = nn.Sequential(*layers)

    def forward(self, x):
        return self.net(x)              # (B, num_classes) logits

    @torch.no_grad()
    def predict(self, x):
        self.eval()
        return self.forward(x).argmax(dim=1)   # (B,)
```

## 4. 兜底方法对照

当对应模型的权重文件（`.pth`）不存在时，推理脚本自动切换到传统/规则方法，保证链路完整：

| 任务 | 正常实现 | 兜底实现 | 触发条件 |
| :--- | :--- | :--- | :--- |
| 分割 | `Segmentor` | `utils/baseline.hsv_water_mask` 颜色阈值 | `checkpoints/seg_best.pth` 缺失 |
| 预测 | `LSTMPredictor` | `infer_video.linear_extrapolate` 线性外推 | `checkpoints/lstm_best.pth` 缺失 |
| 融合 | `RiskFusionNet` | `config.rule_risk_index` 规则阈值 | `checkpoints/fusion_best.pth` 缺失 |

---

## 5. 模型权重加载约定

三个训练脚本均将最优模型保存为 `state_dict`：

| 模型 | 权重路径（config 中定义） | 检查点变量 |
| :--- | :--- | :--- |
| 分割 | `checkpoints/seg_best.pth` | `SEG_CHECKPOINT` |
| LSTM | `checkpoints/lstm_best.pth` | `LSTM_CHECKPOINT` |
| 融合 | `checkpoints/fusion_best.pth` | `FUSION_CHECKPOINT` |

推理端的加载函数（`infer_video.py` 中的 `load_segmentor / load_lstm / load_fusion`）均先判断权重文件是否存在，不存在则返回 `None`，`main` 据此决定是否启用兜底。
