# 03 工具模块说明（utils）

`utils/` 目录包含四个工具模块，负责视频读取、评估指标、可视化绘制与 HSV 兜底分割。各模块职责独立，供训练脚本与推理脚本复用。

---

## 1. `utils/video_processing.py` — 视频读取与序列切窗

### `read_video_info(path) -> (fps, total)`

用 `cv2.VideoCapture` 打开视频，返回 `(fps, 总帧数)`。打开失败抛出 `FileNotFoundError`；`fps` 读取失败时默认 25.0。

### `iter_frames(path, step=1, resize=None) -> Iterator[np.ndarray]`

按步长迭代读取视频帧（BGR 格式）的生成器：

- `step`：帧步长，`step=1` 表示逐帧；
- `resize=(w, h)`：可选缩放；
- 通过 `idx % step == 0` 控制采样。

### `series_from_ratios(ratios, sample_interval=2.0) -> pd.DataFrame`

由面积比序列生成时序特征 DataFrame，列为 `time`、`ratio`、`change_rate`。其中变化率：

```python
change[1:] = np.diff(ratios) / max(sample_interval, 1e-6)
```

### `build_lstm_dataset(ratios, seq_len=10, future_steps=10) -> (X, y)`

切窗生成 LSTM 训练样本，是 `train_lstm.py` 的核心数据构造函数：

- 特征 `X`：`(M, seq_len, 2)`，两维分别为 `[面积比, 变化率]`；
- 标签 `y`：`(M, future_steps)`，为未来 `future_steps` 个时刻的面积比；
- 滑动窗口遍历序列，样本数 = `len - future_steps - seq_len + 1`；
- 序列长度不足时抛出 `ValueError`。

### `pad_to_seq(values, seq_len) -> np.ndarray`

在线推理时，长度不足 `seq_len` 则用首值复制补齐到 `seq_len`，长度足够则取最后 `seq_len` 个值。保证 LSTM 输入维度稳定。

## 2. `utils/baseline.py` — HSV 传统兜底分割

### `hsv_water_mask(bgr, min_area=200) -> np.ndarray`

不使用深度学习，通过 HSV 颜色空间阈值检测积水区域，返回 `0/1` 二值掩码（uint8）。用于分割模型无权重时的兜底。

检测逻辑：

1. **灰白反光水面**：低饱和 + 中等亮度 `(s < 80) & (v > 40) & (v < 220)`；
2. **偏蓝较深积水**：`(h > 90) & (h < 130) & (s > 35) & (v > 50)`；
3. 两个条件取并集；
4. **形态学去噪**：先开后闭（5×5 椭圆核）；
5. **过滤小连通域**：`cv2.findContours` 后仅保留面积 `>= min_area` 的区域。

## 3. `utils/metrics.py` — 评估指标

提供分割、回归与分类评估函数，输入均为 numpy 数组：

| 函数 | 类型 | 公式/含义 |
| :--- | :--- | :--- |
| `dice_coef(pred_mask, gt_mask)` | 分割 | Dice 系数，`2|P∩G| / (|P|+|G|)` |
| `iou(pred_mask, gt_mask)` | 分割 | 交并比 |
| `mIoU(pred_masks, gt_masks)` | 分割 | 多张掩码平均 IoU |
| `mae(pred, target)` | 回归 | 平均绝对误差 |
| `rmse(pred, target)` | 回归 | 均方根误差 |
| `classification_metrics(pred, target, num_classes)` | 分类 | Accuracy、Macro-F1、各类别 Recall |

训练脚本复用这些公共指标：分割验证输出 Dice、IoU、Precision、Recall；LSTM 输出 MAE、RMSE；融合模型输出 Accuracy、Macro-F1 与各风险等级 Recall。

## 4. `utils/visualization.py` — 可视化绘制

依赖 `cv2` 与 `config`（风险颜色、预案文案均取自配置）。

### `overlay_mask(frame, mask, color=(0,0,255), alpha=0.45) -> np.ndarray`

将二值掩码以半透明颜色叠加到帧上：把 mask 区域填充为指定颜色，再用 `cv2.addWeighted` 与原帧混合。

### `draw_risk_panel(frame, info: dict) -> np.ndarray`

在帧上绘制风险信息面板，`info` 需包含：

- `area_ratio`：当前积水面积比；
- `change_rate`：面积变化率；
- `risk_idx`：风险等级索引 0-3；
- `pred_ratio`（可选）：未来预测比；
- `rain`（可选）：降雨强度。

绘制内容：

1. **顶部色条**：整宽度 46px 高的色块，颜色对应风险等级 BGR 色；
2. **风险文字**：`风险等级: 蓝 低风险` 等；
3. **信息行**：面积比、变化率、预测比、降雨强度；
4. **底部预案条**：黑色底条上显示 `config.EMERGENCY_PLAN[risk_idx]` 对应的预案文案。

### `draw_trend_curve(history, out_path)`

将积水面积比历史序列绘制为折线图并保存为 PNG（内部使用 matplotlib 的 `Agg` 后端），X 轴为采样点序号，Y 轴为面积比。
