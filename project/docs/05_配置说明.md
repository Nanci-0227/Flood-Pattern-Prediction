# 05 配置说明（config.py）

`config.py` 是整个项目的全局配置中心。所有模块通过 `import config` 共享同一套路径、超参数、风险分级与预案规则，避免魔法数字散落各处。

`config.py` 模块顶部会在导入时调用 `mkdir(parents=True, exist_ok=True)` 自动创建数据、结果、检查点目录。

---

## 1. 路径配置

| 变量 | 说明 |
| :--- | :--- |
| `ROOT` | 项目根目录（`config.py` 所在目录） |
| `DATA_DIR` | 数据根目录 `data/` |
| `FLOODNET_DIR` | 公开分割训练数据目录 `data/floodnet/` |
| `VIDEO_DIR` | 自采积水验证视频目录 `data/video/` |
| `SERIES_DIR` | LSTM 训练用时序 CSV 目录 `data/series/` |
| `RESULT_DIR` | 输出视频与曲线目录 `result/` |
| `CHECKPOINT_DIR` | 模型权重目录 `checkpoints/` |

## 6. 风险等级映射 `RISK_LEVELS`

键为类别索引，值为 `(名称, 描述, BGR颜色)` 元组：

| 索引 | 名称 | 描述 | BGR 颜色 |
| :---: | :---: | :--- | :--- |
| 0 | 蓝 | 低风险 | (255, 144, 30) |
| 1 | 黄 | 中风险 | (0, 255, 255) |
| 2 | 橙 | 高风险 | (0, 140, 255) |
| 3 | 红 | 极高风险 | (0, 0, 255) |

## 7. 降雨强度分级 `RAIN_LEVELS`

按小时降雨量（mm/h）粗分五级（阈值列表）：

| 阈值 | 分级 |
| :---: | :--- |
| 0.0 | 无降雨/微量 |
| 10.0 | 小雨 |
| 25.0 | 中雨 |
| 50.0 | 大雨 |
| 999.0 | 暴雨及以上 |

## 8. 公安应急处置预案 `EMERGENCY_PLAN`

| 索引 | 预案内容 |
| :---: | :--- |
| 0 | 蓝色预警：加强视频巡查，持续监测积水变化 |
| 1 | 黄色预警：交警到场疏导交通，设置警示标志 |
| 2 | 橙色预警：封闭低洼路段，调配移动抽水设备 |
| 3 | 红色预警：启动应急预案，组织周边疏散并联动多部门抢险 |

## 9. 关键函数

### `rain_level_index(rain_mm_per_h: float) -> int`

将降雨强度（mm/h）映射为等级索引 0..4：返回不超过当前降雨量的最高阈值档位。例如 30 mm/h 对应“中雨”。

### `risk_label(idx: int) -> str`

返回风险等级名称（如 `"蓝"`）。

### `get_device(device_str=None)`

解析运行设备：

- 未传参数时取 `INFER_DEVICE`；
- `"auto"` 时，`cuda.is_available()` 为真则返回 `cuda`，否则 `cpu`；
- 否则直接 `torch.device(device_str)`。

### `rule_risk_index(ratio, pred_ratio, rain_mmh) -> int`

规则兜底：当融合模型不可用时，用阈值映射给出风险等级 0..3。计分规则：

| 条件 | 加分 |
| :--- | :---: |
| `ratio > 0.15` | +1 |
| `ratio > 0.30` | +1 |
| `pred_ratio > 0.35` | +1 |
| 降雨等级 `>= 2`（中雨及以上） | +1 |

最终风险索引 `min(3, score)`。这是融合模型缺失时的兜底方案，也是 `train_fusion.py` 生成伪标签的依据。
