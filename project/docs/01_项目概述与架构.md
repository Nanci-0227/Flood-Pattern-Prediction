# 01 项目概述与架构

## 1. 项目背景与目标

本项目面向城市内涝场景，针对监控视频中的道路积水进行自动识别与风险预警。系统输入一段监控视频，输出叠加了积水掩码、风险信息面板与公安应急预案提示的可视化视频，同时对积水趋势给出预测。

整体目标可拆分为三个递进的子任务：

| 任务 | 内容 | 采用方法 | 对应模型文件 |
| :---: | :--- | :--- | :--- |
| 任务 A | 积水区域识别（语义分割） | U-Net + ResNet50 编码器 | `models/segmentor.py` |
| 任务 B | 积水趋势预测（时序回归） | 双层 LSTM | `models/predictor.py` |
| 任务 C | 风险等级融合（分类） | 轻量 MLP | `models/fusion.py` |

## 2. 系统架构

系统采用「三阶段级联 + 融合」的架构，三个任务分别对应三个相对独立的深度学习模型，最终由融合网络统一输出风险等级：

```
                      ┌─────────────────────────────────────────────┐
                      │                 输入视频                     │
                      └──────────────────────┬──────────────────────┘
                                             │ 逐帧读取
                                             ▼
                      ┌─────────────────────────────────────────────┐
                      │  任务A：积水区域分割                          │
                      │  U-Net 深度分割（无权重时回退 HSV 阈值兜底）  │
                      └──────────────────────┬──────────────────────┘
                                             │ 计算面积比 ratio / 变化率
                                             ▼
                      ┌─────────────────────────────────────────────┐
                      │  任务B：趋势预测                              │
                      │  LSTM 时序回归（无权重时线性外推兜底）        │
                      └──────────────────────┬──────────────────────┘
                                             │ 预测面积比 pred_ratio
                                             ▼
                      ┌─────────────────────────────────────────────┐
                      │  任务C：多模态风险融合                        │
                      │  MLP：面积比 + 变化率 + 预测比 + 降雨强度      │
                      │  （无权重时规则阈值映射兜底）                  │
                      └──────────────────────┬──────────────────────┘
                                             │ 风险等级 0-3
                                             ▼
                      ┌─────────────────────────────────────────────┐
                      │  可视化输出                                   │
│  掩码叠加 + 风险面板 + 预案条 + 趋势曲线 + 事件审计 │
                      └─────────────────────────────────────────────┘
```

## 3. 核心数据流

系统在推理时维护一条「时间序列历史」`history`，记录每个采样时刻的积水面积比，作为 LSTM 预测的输入：

1. **读帧**：`utils/video_processing.iter_frames` 逐帧读取视频（BGR）。
2. **分割**：每帧送入分割模型得到二值掩码，`ratio = mask.mean()` 得到积水面积占比。
3. **采样**：按固定采样间隔（默认 2 秒）将 `ratio` 追加进 `history`。
4. **预测**：当 `history` 长度达到 `SEQ_LEN`（10）时，调用 LSTM 预测未来面积比；否则用当前值。
5. **融合**：将 `ratio`、变化率、预测比、降雨强度拼成 5 维特征，送入 MLP 得到风险等级。
6. **风险状态与可视化**：风险升级立即生效，降级需连续低风险采样确认；掩码按风险色叠加到帧上，最后导出趋势曲线 PNG 与 `risk_events.csv` 事件审计日志。

特征维度约定：

| 特征 | 含义 | 来源 |
| :--- | :--- | :--- |
| `ratio` | 当前积水面积比 | 分割结果 |
| `change_rate` | 面积比变化率 | 历史序列差分 |
| `pred_ratio` | 未来预测面积比 | LSTM 输出 |
| `rain` | 降雨强度 mm/h | 用户传入参数 |
| `drain_rate` | 历史排水速率（可选） | 训练数据可选列 |

## 5. 关键技术设计

1. **统一配置中心**：`config.py` 集中管理所有路径、超参数、风险分级与预案规则，所有模块共享，避免魔法数字。
2. **多级兜底**：分割、预测、融合三个环节均设计了无权重时的兜底方案，使系统在数据准备尚不完整时也能端到端跑通演示。
3. **类别不平衡处理**：分割训练采用 Focal + Dice 组合损失，缓解积水区域占比小导致的类别不平衡。
4. **混合精度训练**：分割训练启用 fp16 AMP，加速训练并降低显存占用。
5. **在线推理填充**：`pad_to_seq` 对长度不足的序列用首值补齐，保证 LSTM 输入维度稳定。
6. **风险状态稳定**：`utils/risk_state.py` 用中位数窗口抑制抖动，同时保留高风险的即时升级能力。
